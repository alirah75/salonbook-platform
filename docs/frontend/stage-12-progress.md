# وضعیت مرحلهٔ ۱۲

- پنل مدیر سالن، مدیر لاین و کارمند در `/dashboard` و پنل مستقل مدیر کل در `/platform` تکمیل شد.
- نمای کلی، نوبت‌ها و عملیات آن، خدمات و لاین‌ها، تیم و مهارت، برنامهٔ هفتگی و مرخصی، حساب‌ها، نقش‌ها و تنظیمات به API واقعی وصل‌اند.
- محدودیت سالن/لاین/کارمند با مجوزهای سرور و RLS رعایت می‌شود؛ نوبت شخصی کارمند آمار کاری او را گسترش نمی‌دهد.
- ورود مدیر کل هم موبایلی است؛ سرویس، اتصال دیتابیس، cookie و محدودسازی ورود آن مستقل‌اند. ایجاد سالن، تعلیق، دامنه و تاریخچه دارای دلیل و شناسهٔ عامل‌اند.
- migration 0011، بازگردانی امن و حفظ اطلاعات تاریخی بررسی شدند.
- ۳۶۴ آزمون سرور، ۲۵ آزمون رابط و هر ۱۰ سناریوی مرورگر موفق شدند. بررسی نوع، lint، format، اسناد schema و ساخت Production موفق‌اند.
- تصاویر دسکتاپ و موبایل روشن/تیره بازبینی شدند. پیش‌نمایش فعلی با `--dashboard-demo` فعال است؛ راهنمای حساب‌های همان اجرا در `backend/.local/preview-accounts.md` است.
- مرحلهٔ ۱۲ در ۲۰۲۶-۱۰-۰۵ کامل شد؛ [گزارش بررسی](verification-stage-12.md) و [تصمیم‌ها و راهنمای اجرا](../architecture/stage-12.md).
- مرحلهٔ بعد: مرحلهٔ ۱۳، گزارش‌های مالی و نمودارها. این مرحله هنوز شروع نشده است.
