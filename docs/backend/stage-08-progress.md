# وضعیت مرحلهٔ ۸

> این گزارش تاریخی است. مرحلهٔ ۹ اکنون اجرا شده؛ وضعیت جاری را در [مرحلهٔ ۹](stage-09-progress.md) ببینید.

کاربر با «مرحله بعد» و سپس «ادامه بده» اجرای مرحلهٔ ۸ را مجاز کرده است. مرحلهٔ ۷ تکمیل و مرحلهٔ ۹ هنوز مجاز نشده است. ورود فقط موبایل/رمز و بدون ایمیل است؛ OTP بعداً اضافه می‌شود و اکنون شرط ساخت نوبت نیست.

پیاده‌سازی جاری: API نوبت، Hold، تأیید رایگان/با شواهد معتبر پرداخت، لغو، جابه‌جایی با snapshot ثابت، تکمیل/عدم حضور، تاریخچه، Outbox و Audit، idempotency هفت‌روزه، version، قفل مشتری و کارمند مرتب‌شده بعد از قفل اشتراکی CalendarControl، انقضای تنبل و Worker صریح سالن. هیچ درگاه یا شواهد پرداخت ساختگی در API اضافه نشده است. تمام نوبت‌ها فعلاً is_test=true هستند؛ مرحلهٔ ۹ معماری پرداخت Mock را وصل می‌کند.

Migration 0009 شامل مجوزهای نوبت و no_show_grace_minutes است. پیش‌نمایش موقت تازه پس از اتمام بررسی‌ها جایگزین نمونهٔ مرحلهٔ ۷ می‌شود. CLI انقضا `scripts.expire_holds` است و محیط preview نیز Worker خودش را دارد.

مرحلهٔ ۸ کامل است: هر ۳۲۷ آزمون در اجرای کامل با زمان 297.59s موفق شدند. آزمون ۵۰ مشتری HTTP هم‌زمان دقیقاً یک Hold موفق و ۴۹ پاسخ تداخل داشت. HTTP واقعی، Ruff، mypy برای ۱۲۳ فایل، schema docs و lockfile موفق‌اند. قرارداد در [stage-08.md](../architecture/stage-08.md) و شواهد در [verification-stage-08.md](verification-stage-08.md) ثبت شده‌اند.

پیش‌نمایش تازهٔ مرحلهٔ ۸ روی `http://127.0.0.1:8000/api/v1/docs` با Worker انقضای پنج‌ثانیه‌ای اجرا شده و readiness و مسیرها بررسی شده‌اند. محیط موقت مرحلهٔ ۷ متوقف شد؛ دیتابیس ماندگار و پروژه‌های دیگر تغییر نکرده‌اند. پیش‌نمایش عادی مدیر اولیه یا برنامهٔ کاری آماده ندارد؛ گزینهٔ --manager-phone در README توضیح داده شده است.

محل ادامهٔ مرحلهٔ ۹: Provider Mock، Intent/Attempt/Receipt/Allocation، Verify و اتصال آن به `appointments.domain.confirm_verified` در همان تراکنش. ترتیب lifecycle → CalendarControl مشترک → User/Session (برای HTTP) → CustomerProfile → EmployeeProfile مرتب → Appointment → Payment رعایت شود. مبلغ از Snapshot نوبت است. Hold منقضی یا لغوشده با دریافت وجه نباید دوباره ظرفیت بگیرد؛ مسیر دریافت دیرهنگام/Refund و مصرف Outboxهای expired/cancelled/payment_review باید تکمیل شود. ثبت نوبت پولی اکنون Hold می‌سازد و بدون شواهد معتبر تأیید نمی‌شود. مرحلهٔ ۹ هنوز مجوز شروع ندارد.
