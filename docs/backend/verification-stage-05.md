اجرای کامل قبل از افزودن ابزار bootstrap-manager شامل ۲۲۶ آزمون بود. ابزار افزوده‌شده با آزمون مستقل خود بررسی شد؛ جمع نتایج ۲۲۷ است. بررسی استاتیک روی همهٔ فایل‌های نهایی انجام شد.

## موارد پوشش‌داده‌شده

- نام سالن، مشخصات خود، ساخت مشتری/کارمند، فهرست صفحه‌بندی‌شده و فیلتر نوع کاربر.
- جلوگیری از دسترسی مشتری و مدیر لاین به فهرست‌ها و تغییرات مدیریتی کل سالن.
- عدم مشاهده/ویرایش کاربر، نقش یا لاین سالن دیگر؛ RLS و بی‌اثر بودن `X-Tenant-ID`.
- محدود بودن مجوز دیتابیس API به تغییر name سالن؛ منع تغییر status.
- ساخت، تغییر، حذف نرم نقش، انتساب و لغو نقش؛ ثبت مجموعهٔ مجوزهای قبل/بعد در Audit.
- عدم افزایش اختیار از سقف مدیر؛ عدم تبدیل اختیار LINE به TENANT؛ حفاظت نقش سیستمی.
- ابطال نشست هنگام افزایش/کاهش اختیار، غیرفعال‌سازی حساب و تعلیق سالن؛ عدم احیای نشست قدیمی پس از فعال‌سازی.
- حفظ آخرین مدیر، rollback درخواست ناموفق و دو درخواست هم‌زمان برای غیرفعال‌سازی مدیران.
- منع CSRF جعلی، Origin نامعتبر، فیلدهای اضافی، ایمیل، تزریق نقش و شمارهٔ تکراری در سالن.
- ساخت اتمی Tenant همراه تنظیمات، نقش‌ها و مدیر اولیه با اتصال کنترلِ محدود و بدون مالکیت جداول.
- rollback کامل ساخت سالن با دامنهٔ تکراری یا دلیل خالی.
- جلوگیری از اجرای API با اتصال کنترل و جلوگیری از ساخت Tenant با اتصال runtime.
- ثبت غیرفعال دامنه، فعال‌سازی صریح، منع تصاحب دامنهٔ سالن دیگر و رد context قدیمی پس از بازنشستگی دامنه.
- ترتیب تعلیق نسبت به تراکنش در حال اجرا؛ بستن نهایی و ممنوعیت بازفعال‌سازی CLOSED.
- ارتقای نقش‌های سیستمی قدیمی حتی برای سالن بدون دامنه، حفظ نقش سفارشی، downgrade/reupgrade و FORCE RLS.
- تعیین اولین مدیر برای حساب موجود فقط در سالن صحیح، ابطال نشست و ممنوعیت اجرای مجدد در حضور مدیر فعال.

## HTTP واقعی

`scripts.check_management_preview` یک سالن موقت با مدیر و رمز تصادفی در حافظه ساخت. ورود مدیر، تغییر نام سالن، ایجاد کارمند، ورود کارمند، ساخت نقش، انتساب، ورود مجدد پس از افزایش اختیار، حذف مجوز، ورود مجدد با اختیار کمتر، غیرفعال‌سازی حساب و حذف نقش بررسی شدند. نتیجه:

```text
PASS: real HTTP salon, user, employee, roles, permissions and session revocation checks.
```

فرایند و دیتابیس این آزمون پس از پایان جمع شدند. شماره، رمز و توکن چاپ نشدند. پیش‌نمایش تعاملی معمول روی پورت ۸۰۰۰ جداگانه اجرا می‌شود.

موفقیت این آزمون‌ها به معنی انتشار production یا پیاده‌سازی رابط مدیریت نیست. در این مرحله SMTP، SMS، OTP یا ورود وبِ Super Admin اضافه نشده‌اند؛ مدیریت پلتفرم ابزار آفلاین با اتصال مستقل است.
